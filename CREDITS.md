# Credits

## Graphics and fonts

Some or all of the graphics and fonts are from **Sprout Lands** by **Cup Nooble**: https://cupnooble.itch.io/

- **Sprout Lands - Sprites - premium pack**: tiles, characters, animals and objects in `android/assets/maps/` and
  `android/assets/sprites/`.
- **Sprout Lands - UI Pack - Premium pack**: UI pieces (buttons, dialog boxes, icons, emotes) in `android/assets/ui-pack/`,
  and the bitmap fonts in `android/assets/ui-pack/fonts/`, made from the pack's pixel fonts.

The packs themselves are not in this repository: only the parts the game uses, packed into atlases and bitmap fonts by
`tools/assets/build_assets.py`.
